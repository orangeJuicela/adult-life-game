## Background music

**Chill lofi inspired [loop edit]**

- Music: omfgdude
- Seamless loop edit: qubodup
- Source: https://opengameart.org/content/chill-lofi-inspired-loop-edit
- Original recording: https://opengameart.org/content/chill-lofi-inspired
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)

Both OpenGameArt pages list the license as CC0 and link to the Creative Commons public-domain dedication. The original is a one-take lo-fi hip-hop recording on a Yamaha CVP-701 (piano and drums). qubodup edited that recording into a seamless loop. The game uses `site/assets/bgm.mp3`, encoded from that Ogg download at 128 kbps. CC0 does not require credit; the names and links above are kept so the source stays easy to find.

## Sound effects

Dialogue taps, choice clicks, the correct-answer chime, the soft wrong-answer buzz, XP, knowledge cards, sorting, and the ending stars are synthesized in the browser with the Web Audio API (`site/audio.js`). They are not third-party recordings.
